# Design Reference

레퍼런스 파일 `child-counseling-center.html`은 프로젝트에 포함되어 있지 않습니다.
2026-07-28 리뉴얼은 지시서(디자인 토큰, 섹션별 구조, QA 체크리스트)를 기준으로 `index.html`에 직접 반영했습니다.

## 적용된 디자인 시스템

- 컬러: navy / sage / sand / gold 토큰
- 타이포: Nanum Myeongjo + Pretendard Variable
- 아이콘: 이모지 제거, SVG 라인 아이콘
- 섹션: Hero, Philosophy, About, Programs, Therapists, Media, FAQ, Contact
